# JW Conf Patcher - User Instructions

**What this does**: Fixes bugs in JW Conf Windows application  
**How long**: 2 minutes  
**Difficulty**: Super easy - just double-click!

---

## Installation (For End Users)

### Step 1: Download the Installer

Download: **JWConf-Patcher-Setup.exe**

### Step 2: Close JW Conf

If JW Conf is running, close it completely.

### Step 3: Run the Installer

1. **Double-click**: `JWConf-Patcher-Setup.exe`
2. **If Windows asks**: Click "Yes" to allow changes
3. **If SmartScreen appears**: Click "More info" → "Run anyway"
4. **Click "Next"** through the wizard
5. **Wait** for installation (about 1 minute)
6. **Click "Finish"**

### Step 4: Restart JW Conf

Open JW Conf and test the fixes!

## Troubleshooting

### "JW Conf is not installed"

**Fix**: Install JW Conf first from jwconf.com, then run this patcher

### "Windows SmartScreen blocked this app"

**Fix**: 
1. Click "More info"
2. Click "Run anyway"
3. This is normal for unsigned installers

### "Installation failed"

**Fix**:
1. Make sure JW Conf is closed
2. Run the installer as Administrator (right-click → "Run as administrator")
3. Try again
